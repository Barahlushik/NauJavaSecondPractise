
# Практические задания (вариант №4)

## 1. Работа с массивом. [Код](https://github.com/Barahlushik/NauJavaSecondPractise/tree/feature/practice-tasks/src/main/java/org/example/first)

### Условие
Заполните массив (тип элементов `int`) случайными числами и выполните задание в соответствии со своим вариантом.


### Вариант задания
`Найти последний положительный элемент в массиве.`

### Входные данные

n — количество элементов в формируемом массиве
диапазон: [0, ∞)

### Выходные данные
В консоль напечатаны:

- массив
- результат поиска в соответствии с заданием

## 2. Работа со списками. [Код](https://github.com/Barahlushik/NauJavaSecondPractise/tree/feature/practice-tasks/src/main/java/org/example/second)

### Условие
Заполните список (тип `ArrayList<Double>`) случайными числами и отсортируйте его.

Метод сортировки выбирается в соответствии с вашим вариантом.

Сортировку необходимо реализовать **вручную** (не использовать встроенные возможности Java или сторонних библиотек).

### Вариант задания

`Selection Sort (сортировка выбором)`

### Входные данные

n — количество элементов в формируемом списке
диапазон: [0, ∞)

### Выходные данные
В консоль напечатаны:

- исходный список
- отсортированный список

---

## 3. Stream API. [Код](https://github.com/Barahlushik/NauJavaSecondPractise/tree/feature/practice-tasks/src/main/java/org/example/third)

### Условие
Необходимо обработать список с использованием **Stream API**.

Задание состоит из нескольких этапов.

### 1. Реализация класса Employee

Необходимо реализовать java-класс сотрудник: Employee.java 

Класс Employee.java содержит приватные поля:
- fullName — ФИО (String)
- age — возраст (Integer)
- department — отдел (String)
- salary — заработная плата (Double)

Класс должен содержать:

- геттеры
- сеттеры

### 2. Создание списка сотрудников

Необходимо реализовать предзаполненный список: ArrayList\<Employee>


Список должен содержать **не менее 5 элементов**.

### 3. Выполнение задания

При выполнении задания необходимо использовать **Stream API**.

#### Вариант задания
`Преобразовать список сотрудников в список строк вида: "Имя - Отдел"`

### Выходные данные
В консоль напечатан результат выполнения задания.

Объекты должны быть выведены **в читаемом виде**.

## 4. HTTP клиент и JSON. [Код](https://github.com/Barahlushik/NauJavaSecondPractise/tree/feature/practice-tasks/src/main/java/org/example/fourth)

### Условие
Необходимо сделать **GET запрос** на указанный адрес и обработать ответ.

Запрос выполняется на тестовый сервер: https://httpbin.org/

Сервер возвращает ответ в формате **JSON**.

Из ответа необходимо извлечь и вывести информацию в консоль в соответствии со своим вариантом.

### Вариант задания
`Вывести только допустимые типы ответа (поле Accept) из заголовков.`

Запрос выполняется по адресу: https://httpbin.org/anything

### Выходные данные
В консоль напечатан результат выполнения запроса, обработанный в соответствии с вариантом задания.

## 5. Реализация интерфейса Task. [Код](https://github.com/Barahlushik/NauJavaSecondPractise/tree/feature/practice-tasks/src/main/java/org/example/fifth)

### Условие
Необходимо реализовать интерфейс: Task.java

в соответствии со своим вариантом задания.

### Вариант задания
Реализуйте интерфейс Task для обработки данных, поступающих в очередь. Процесс обработки имитируется выводом сообщения в консоль.

Метод `start()` начинает чтение и обработку данных из очереди, а `stop()` останавливает процесс.
